### Что исправлено в 3.3.9

1. **Запоздавшая смена аккаунта.** Только последний запрос выбора может сохранить активный аккаунт. Записи в хранилище упорядочены; popup и панель игнорируют устаревшие ответы. При ошибке последнего выбора восстанавливается подтверждённый аккаунт. Создание блокнота сохраняет аккаунт, с которого оно было запущено.
2. **Дублирование после потери ответа.** Очередь сохраняет снимок существующих ID до отправки POST. Ошибки транспорта, HTTP 5xx и повреждённые ответы считаются неопределённым исходом. Повторная обработка сверяет блокнот, учитывая появление нового ID и канонические YouTube URL, вместо повторного POST. Снимок сохраняется при перезапуске worker и в резервной копии.
3. **Отмена и перезапуск очереди.** Пробуждение новой очереди ожидает завершения текущего worker и затем повторно проверяет актуальное задание. Старый run больше не может очистить таймер нового. Проверен запуск нового задания в течение нескольких секунд, без ожидания минутного watchdog.
4. **Частично успешный массовый импорт.** Возвращаются статусы каждого входного URL: `added`, `failed`, `pending`, `uncertain`. Успешные ответы записываются в историю до следующего RPC. Popup оставляет для повтора только ошибочные и неотправленные URL; менеджер вкладок снимает выбор с подтверждённых и неопределённых операций. Неопределённые результаты показаны отдельным списком.

### Дополнительно проверено

- Ошибка старого запроса авторизации после успешного нового; ошибка нового при незавершённом старом; задержка записи аккаунта в `storage.sync`.
- Реальный `fetch` Chromium с потерей ответа после записи источника на тестовом сервере: один POST, один источник, один подтверждённый элемент очереди.
- Задержка появления нового источника в списке; наличие старого источника с тем же URL; повторная проверка через кнопку ручного повтора.
- Восстановление неопределённой операции после перезапуска и запрет её незаметного переноса в другой аккаунт или блокнот.
- Частичные результаты для повторяющихся URL с сохранением исходных позиций; сбой истории после подтверждённого импорта.
- Частичный импорт и повтор в popup и менеджере вкладок; исключение неопределённого POST из следующей отправки.

**Особенность неопределённых операций:** отсутствие источника сразу после сетевого обрыва не доказывает отказ сервера. После исчерпания проверок элемент остаётся с ошибкой и сохранённым снимком. Ручной повтор снова проверяет блокнот. Отдельное новое добавление такого URL следует делать после проверки источников в Google.

Новые сетевые сбои и перестановки ответов воспроизводятся управляемыми фикстурами. Браузерные проверки используют настоящий Chromium, service worker, хранилище и обмен сообщениями расширения. Перечисленные ниже сквозные проверки настоящей Google-сессии относятся к предыдущему этапу 3.3.8; в этом прогоне повторно они не выполнялись.

## Исправленные ошибки

### Обмен сообщениями и Google RPC

- Общий клиент `lib/extension-client.js` распаковывает `{ result }`, передаёт ошибки `{ error }` в интерфейс и очищает таймер ожидания.
- Поле `error: null` в объекте статуса парсинга больше не считается ошибкой команды.
- Разбор `batchexecute` поддерживает ответы с префиксом защиты, строками длины и несколькими JSON-конвертами. Слово `error` в обычном содержимом не вызывает ложный отказ.
- Добавление, удаление и синхронизация распознают RPC-ошибки внутри HTTP 200.
- Токены изолированы по аккаунтам и обновляются после истечения срока кеша. Аккаунт страницы и аккаунт запущенного задания учитываются отдельно от глобального выбора в popup.
- ID блокнота извлекается из структуры ответа, а не из первой UUID-подобной строки в названии.
- Проверка текстового импорта сопоставляет новые ID и учитывает задержку регистрации источника.

### Очередь и история

- Конкурентные записи больше не перезаписывают другие добавленные элементы или записи истории.
- Элементы удаляются по стабильному ID; статус очереди соответствует реальному выполнению.
- Автоматически выполняются до трёх попыток, после чего ошибка сохраняется для ручного повтора.
- Состояние очереди, аккаунт и блокнот сохраняются в `storage.local`; обработка восстанавливается после перезапуска Chrome.
- Таймер обслуживает короткие задержки, alarm watchdog восстанавливает остановившийся worker.
- Проверены добавление/очистка очереди во время сетевого запроса, устаревшие alarms и сбои записи после успешного RPC.
- Ошибки прямых операций записываются в историю и доступны поиску. Лимит истории — 500 записей.

### PDF и Drive

- Горячая клавиша и контекстное меню PDF используют выбранный блокнот; при отсутствии выбора сохраняется исходная вкладка для дальнейшего действия в popup.
- Сохранение ожидающего PDF обращается к исходной вкладке, а не к текущей активной.
- Исправлен актуальный формат регистрации PDF: Google возвращает полный дескриптор источника с вложенным `[sourceId]`.
- PDF проверяется перед регистрацией; передаются бинарные данные, сохраняются кириллические имена. Проверены отсоединение debugger при ошибке и тайм-ауте, очистка созданной заготовки при сбое загрузки.
- Исправлено определение актуальности Drive по реальному ответу `[[null, isFresh, [sourceId]]]`. Сохранена совместимость с прежними числовыми ответами.
- Ошибки Drive отличаются от источников, для которых актуальность определить не удалось.

### YouTube, RSS и Sitemap

- Исправлено несоответствие `new` / `newest`, сохранение лимита `0`, применение лимита в режиме Top.
- Восстановлены ответы из старого renderer-формата и связи `commentKey` с новыми entity-ответами.
- Комментарии и continuation tokens дедуплицируются. Родитель ответа сохраняется между страницами даже для ID без встроенного parent ID.
- Сетевые ошибки и временные HTTP-ошибки повторяются; запрос имеет тайм-аут.
- Отмена ожидает завершения текущего запроса и не позволяет прежнему заданию перезаписать состояние нового. Прерванный worker оставляет понятный статус.
- XML разбирается через `DOMParser` в offscreen-документе: RSS, Atom, namespaces, CDATA, `xml:base`, Sitemap и индексы Sitemap.
- Автообнаружение RSS сначала разбирает ленту, затем предлагает статьи для очереди.
- Исправлены нормализация YouTube-ссылок и возможность выбирать ссылки после прежнего ограничения в 50 строк.

### Интерфейс, настройки и удаление

- Названия источников и `aria-label` больше не принимаются за ID. Это устраняет удаление другого источника, если название содержит UUID.
- Неоднозначные одинаковые названия не сопоставляются произвольно; в popup доступен выбор по точным ID API.
- Строки удаляются из интерфейса только после подтверждённого успешного ответа. Учитывается смена блокнота во время запроса.
- Исправлены обновление кеша источников, включение панели после отключения, обработка поздно появляющихся строк, навигация и сохранение позиции панели.
- Приведены к одному ключу настройка уведомлений и её обработчик.
- Резервная копия сохраняет реальные ключи, мигрирует старые и проверяет значения до записи.
- Исправлены недостающие переводы, подстановки, отображение обычного текста ошибок, запасные иконки и импорт вкладок из нескольких окон.

## Область покрытия

Браузерный набор покрывает все разделы popup, страницу вкладок, плавающую панель, настройки, резервные копии, парсеры и обработку ошибок. Ответы сервисов в этом наборе воспроизводятся фикстурами; перечисленные выше сквозные проверки выполнены дополнительно через настоящие Google и YouTube.

- Несколько аккаунтов и сбои сети/хранилища проверены автоматизированными сценариями; настоящая Google-сессия содержала один аккаунт.
- Обработчики горячих клавиш, контекстного меню и уведомлений проверены модульными тестами. Физические сочетания клавиш Windows и внешний вид системных уведомлений отдельно не проверялись.
- Минимальная версия Chrome 116 сохранена в манифесте; фактический браузерный прогон выполнен в Chrome 158.

## Причины затруднений предыдущих запусков

Служебная автоматизация первоначально обращалась к устаревшим контекстам после перезагрузки расширения; стандартное подключение Playwright к открытому вручную Chrome также завершалось по тайм-ауту. Для сквозной проверки использованы новое окно расширения и ограниченные по времени CDP-команды.
В адаптивном интерфейсе Google список источников был скрыт вкладкой «Чат»; проверка панели переведена на вкладку `Sources`.
Отдельно найдены и исправлены реальные несовпадения форматов ответов PDF и Drive; они закреплены регрессионными тестами.

Команды повторного запуска и установка расширения: [TESTING.md](TESTING.md).
